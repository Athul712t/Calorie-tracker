# CalorieTrack

AI calorie tracker for Android. Log a meal by photo, text or search, see calories and macros against a personalised daily target, and track weight and progress photos.

- Product and screen spec: `docs/SPEC.md`
- Design reference and tokens: `docs/design/`
- Contributor rules: `AGENTS.md`

## Build
Open in Android Studio, or run `./gradlew assembleDebug`. Firebase needs a `google-services.json` for your project in `app/`.
